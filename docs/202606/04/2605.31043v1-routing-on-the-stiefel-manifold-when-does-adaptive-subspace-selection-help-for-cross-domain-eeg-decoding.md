## 摘要
尽管黎曼深度学习取得了进展，跨领域脑电解码仍然具有挑战性：来自不同受试者的协方差矩阵在SPD流形上占据系统性的不同区域，然而现有的领域自适应方法要么需要目标领域的校准数据，要么学习无法跨领域泛化的受试者特定成分。我们提出了动态斯提费尔路由：一组在斯提费尔流形上的K个专家投影滤波器，每个滤波器专门针对SPD流形上的不同区域，通过交叉注意力将每个输入协方差路由到最合适的滤波器，从而根据样本调整子空间投影。一个核心发现是，这种朴素实现的方法可证明会退化为集成平均：当路由权重均匀时，自适应滤波器正好等同于专家等贡献组合，与单一固定滤波器无法区分。三种结构特性打破了这种简并性：一个对称锚点W_base ∈ St(n,k)消除了专家间的邻近偏差；一个冻结的领域判别查询编码器将路由与任务优化解耦；一个解耦的键对齐损失将专家键训练为稳定的领域吸引子。它们共同产生了SPD流形上第一个真正具有承诺性和领域结构化的路由，在三个数据集上取得了一致的提升：平衡准确率分别从0.773→0.823、0.757→0.809和0.801→0.839，且对齐策略由单一数据驱动规则自动确定，无需数据集特定的超参数搜索。

## Abstract
Cross-domain EEG decoding remains challenging despite advances in Riemannian deep learning: covariance matrices from different subjects occupy systematically distinct regions of the SPD manifold, yet existing domain adaptation methods either require target-domain calibration data or learn subject-specific components that cannot generalise across domains. We propose dynamic Stiefel routing: a pool of $K$ expert projection filters on the Stiefel manifold, each specialised for a different region of the SPD manifold, with each input covariance routed to the most appropriate filter via cross-attention, adapting the subspace projection per sample. A central finding is that this approach, implemented naively, provably collapses to ensemble averaging: when routing weights are uniform, the adaptive filter reduces exactly to an equal-contribution combination of experts, indistinguishable from a single fixed filter. Three structural properties break this degeneracy: a symmetric anchor $W_{\mathrm{base}} \in \mathrm{St}(n,k)$ that removes proximity bias among experts; a frozen domain-discriminative query encoder that decouples routing from task optimisation; and a decoupled key alignment loss that trains expert keys toward stable domain attractors. Together they produce the first genuinely committed and domain-structured routing on SPD manifolds, with consistent gains across three datasets: balanced accuracy improves from $0.773\to 0.823$, $0.757\to 0.809$, and $0.801\to 0.839$, with the alignment strategy determined automatically by a single data-driven rule and no dataset-specific hyperparameter search.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：跨领域脑电解码（cross-domain EEG decoding）面临严重的域偏移（domain shift）——不同受试者的协方差矩阵在对称正定（SPD）流形上占据系统性的不同区域。现有方法要么需要目标域的校准数据（如 Riemannian Procrustes Analysis），要么学习受试者特定成分而无法泛化。标准的 SPDNet 使用固定的 BiMap 滤波器（W⊤XW），对所有样本采用同一子空间投影，忽视了输入所属的域结构。
- **整体含义**：作者提出在 Stiefel 流形（St(n,k)）上维护一个专家投影滤波器池，通过交叉注意力动态地为每个输入协方差选择最合适的滤波器，从而实现样本自适应的子空间选择。核心发现是，朴素的路由实现会退化为集成平均（ensemble averaging），即路由权重均匀，滤波器等价于等贡献组合，无任何样本自适应能力。论文通过三种结构修复打破了这种简并性，首次在 SPD 流形上实现了真正“承诺性”（committed）且域结构化的路由。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
- 保持 K 个专家滤波器 {W_j} ⊂ St(n,k)，每个滤波器对应不同的流形区域。
- 对每个输入协方差 X_i ∈ SPD(n)，通过交叉注意力计算路由权重 α_i ∈ Δ^{K-1}，然后利用权重对专家进行 Riemannian 插值得到样本特定的滤波器 W_i，最终输出 Y_i = W_i^⊤ X_i W_i ∈ SPD(k)。
- 朴素实现导致权重均匀，退化为固定滤波器。三种机制解决：
  1. **对称锚点 W_base**：一个独立学习的参数，作为插值的参考点，消除任何专家因邻近 W1 而获得的梯度优势。
  2. **冻结域判别查询编码器（DSP）**：通过计算训练域间散度的前 r 个特征向量，将 log-协方差的切空间投影到低维域判别子空间，冻结该投影，为路由提供稳定的域信号。
  3. **解耦键对齐损失**：专家键 E_j 仅通过对齐损失（余弦相似度）向当前样本的查询（stop-gradient）的获胜者更新，且从分类梯度中断开（decouple_keys），防止键成为移动目标。

### 关键技术细节
- 在 Stiefel 流形上使用切空间投影和 QR 收缩作为近似指数/对数映射。
- 路由权重由查询 q_i（由投影后的切向量 ˜x_i 与可学习域嵌入 Emb(d_i) 拼接后经 MLP 得到）与可学习键矩阵 E 的点积 softmax 得到。
- 诊断指标：
  - **K=1 代理间隙** Δ_{K=1}：自适应模型与单个等贡献专家滤波器（即所有专家平均）的准确率差，>0 表示真正路由。
  - **路由熵** H̄：衡量权重分布均匀程度，<0.7 表示承诺性路由。
  - **域对齐比** r_d：域平均路由向量的方差与总体方差之比，>0.1 表示路由按域结构化。

### 算法流程（文字描述）
1. 输入批次 SPD 矩阵 {X_i} 和域索引 {d_i}。
2. 对每个 X_i：计算 log(X_i) 并提取上半三角得到切向量 x_i；若 ρ > ρ* 则通过 DSP 投影得到 ˜x_i（否则直接用 x_i）；拼接域嵌入 Emb(d_i) 后送入 MLP 得到查询 q_i。
3. 计算 α_i = softmax(q_i E^⊤ / √m)。
4. 在锚点 W_base 处计算各专家的切向量投影 Δ_j = P_{W_base}(W_j)。
5. 计算加权平均 ¯Δ_i = Σ_j α_{i,j} Δ_j，然后通过 QR 收缩得到 W_i = R_{W_base}(¯Δ_i)。
6. 应用 BiMap 得到 Y_i = W_i^⊤ X_i W_i，输入后续 ReEig → LogEig → 线性分类层。
7. 总损失 L = L_CE + λ_align * L_align（仅更新获胜者键，且当 decouple_keys=True 时键不接收 L_CE 梯度）。

## 3. 实验设计

### 数据集

- **BNCI2014001**：n=22，D=9，ρ=28（中间ρ，接近阈值）。

所有实验为二分类（右手 vs 脚运动想象），采用 5 折交叉验证（70/15/15% 试次级划分）。

### 对比方法

## 6. 论文的主要结论与发现

1. **朴素路由必然退化为集成平均**：路由权重趋于均匀，K=1 代理间隙为零，增益完全来自专家多样性而非自适应。
2. **三个结构修复共同打破简并性**：对称锚点消除邻近偏见；冻结 DSP 提供稳定的域判别查询；解耦键对齐损失防止键成为移动目标。
3. **在三个数据集上实现一致提升**：bAcc 提升约 4-5 个百分点，Δ_{K=1} 显著为正，路由熵降至 0.48-0.67，域对齐比达 0.54-0.83。
4. **统一缩放规则（基于 ρ）自动确定策略**：当 ρ > 50 时启用 DSP 和解耦对齐；否则禁用，无需人工调参。
5. **LOSO 下无改善**：说明当前方法只能适应已知域，零样本泛化仍需进一步工作。
