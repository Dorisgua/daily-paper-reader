## 摘要
本文针对不同任务数据集中的脑电图数据，在神经网络分类器解码中，详细研究了基于独立成分（IC）的噪声抑制方法的效果。我们采用两种流行的独立成分分解方法（Infomax和自适应混合独立成分分析[AMICA]）与三种不同的成分拒绝策略（无拒绝、ICLabel和多重伪迹拒绝算法[MARA]）组成的管道矩阵，应用于三个不同的EEG数据集（运动想象、长期记忆形成和视觉记忆）。我们使用三种常用于EEG分类的架构（两种卷积神经网络和一种基于长短期记忆的模型）对每个管道处理后的数据进行交叉验证。我们比较了参与者内和数据集内的解码性能。我们的结果表明，在解码分析中使用基于IC的噪声抑制带来的好处最多是微小的，因为经过成分拒绝的数据并未表现出比未拒绝数据更一致的性能；尤其考虑到独立成分分析计算所需的大量计算资源。

## Abstract
In this paper, we conduct a detailed investigation on the effect of independent component (IC)-based noise rejection methods in neural network classifier-based decoding of electroencephalography (EEG) data in different task datasets. We apply a pipeline matrix of two popular different independent component (IC) decomposition methods (Infomax and Adaptive Mixture Independent Component Analysis (AMICA)) with three different component rejection strategies (none, ICLabel, and multiple artifact rejection algorithm [MARA]) on three different EEG datasets (motor imagery, long-term memory formation, and visual memory). We cross-validate processed data from each pipeline with three architectures commonly used for EEG classification (two convolutional neural networks and one long short-term memory-based model. We compare decoding performances on within-participant and within-dataset levels.Our results show that the benefit from using IC-based noise rejection for decoding analyses is at best minor, as component-rejected data did not show consistently better performance than data without rejections; especially given the significant computational resources required for independent component analysis (ICA) computations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：基于独立成分分析（ICA）的脑电（EEG）伪迹去除方法，在深度神经网络（DNN）解码任务中是否真正提升分类性能？
- **研究动机**：
  - 传统 EEG 分析（如事件相关电位）中，ICA 伪迹去除是标准预处理步骤，可提高信噪比。
  - 然而，在解码/分类研究中，尤其是使用深度神经网络时，噪声可能被网络隐式忽略或利用，因此去噪并非必然有益。
  - 前期研究在经典机器学习（如 SVM、LDA）中报告了 ICA 去噪可提升性能，但在深度学习中结果不一（有些甚至降低性能）。
  - ICA 计算资源消耗大，需评估其实际收益与成本。
- **论文整体含义**：质疑 ICA 伪迹去除在深度学习解码中的必要性，并通过系统实验给出证据：收益甚微，不值得大规模计算投入。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：构建一个标准化的预处理管道矩阵，比较不同 ICA 分解方法与自动伪迹拒绝方法组合对深度学习分类性能的影响，同时保持其他预处理步骤一致。
- **关键技术细节**：
  - 使用 **PREP 管道** 进行统一的初级预处理（去趋势、陷波滤波、坏道检测/插值、重参考等）。
  - 两种 ICA 分解方法：**RunICA（Infomax）** 和 **AMICA（自适应混合独立成分分析）**。
  - 三种成分拒绝策略：
    - 无拒绝（NoICA，基线）；
    - **ICLabel**：基于神经网络分类器，拒绝非脑类概率 >80% 的成分；
    - **MARA**：基于线性分类器和预定义特征的自动拒绝。
  - 组合成 5 种管道：NoICA、RunICA+MARA、RunICA+ICLabel、AMICA+MARA、AMICA+ICLabel。
  - 分类器：三种深度网络：
    - **ShallowNet**（CNN，专为 EEG 设计）；
    - **EEGNetV4**（紧凑型 CNN）；
    - **MLSTM-FCN**（LSTM+CNN 混合，通用时间序列分类）。
  - 超参数优化分两阶段：
    - 第一阶段：在 BCIC-IV2a 数据集的 NoICA 管道上，优化所有网络共享的参数（学习率、学习率调度参数、早停轮数）。
    - 第二阶段：对每个参与者-管道-网络组合，单独优化网络特定超参数（如卷积核大小、滤波器数量、LSTM隐藏层大小等），采用网格搜索 + 5折交叉验证，以验证集 F1 选取最佳模型。

## 3. 实验设计：数据集、基准、对比方法

- **数据集**：

- **基准**：以 NoICA（无 ICA 去噪）作为基线，对比其他 4 种 ICA 管道。

## 6. 论文的主要结论与发现

- **主要结论**：基于 ICA 的伪迹去除（无论使用何种分解或拒绝方法）**并未给深度网络解码带来一致且有意义的性能提升**，甚至在某些情况下轻微降低性能。
- **关键发现**：
  - 单参与者水平上，部分管道间存在统计显著差异（尤其 MARA 管道与 NoICA/ICLabel 管道之间），但效应量小，且最佳验证性能对应的测试 F1 值在不同管道间高度相似。
  - 跨参与者水平重复测量方差分析中，只有少数比较达到显著性（如 BCIC-IV2a 中 RunICA+ICLabel vs. AMICA+MARA 在 EEGNetV4 上显著），且校正后差异微弱。
  - 即使 MARA 拒绝大量成分（如在长期记忆数据中平均拒绝 30+ 个成分），性能依然与 NoICA 基本持平。
  - 参与者本身（数据来源）是性能的决定性因素，而非预处理管道。
  - ICA 计算耗时巨大，尤其在大数据集上，投入产出比极低。
